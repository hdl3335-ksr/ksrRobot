# First post

This is your first sample post using the Just the Docs theme on a real Jekyll blog structure.

## Writing tips

- Add markdown files under `_posts`.
- Use the `YYYY-MM-DD-title.md` filename format.
- Jekyll will publish posts by date and expose them through `site.posts`.
